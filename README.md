# 汲古 · Jigu

> 一天一首诗，跟着节气过日子。把诗送进生活，而不是把你拉进 App。

**汲古**是一款开源的中文古诗词·古文阅读 Android 应用（Kotlin + Jetpack Compose）。
名出韩愈「汲古得修绠」——从古井打水，要用长绳；亦借明代汲古阁刻书传书之意。

## 特性（规划中）

- **今日一首**：节气 / 物候 / 花信 / 节日引擎驱动的每日推荐，全离线，无信息流
- **书库**：全量唐诗·宋诗·宋词 + 《古文观止》，意象主题「循物寻诗」
- **送出 App**：桌面 widget、每日定时推送、笺纸风分享卡片
- **主题**：宣纸墨色 + 传统色随节气换肤，横竖排切换

## D-001 产品定位（2026-10-24）

一句话：**诗词版岛读——一天一首，跟着节气过日子；把诗送进生活，而不是把用户拉进 App。**
- 内容：中国古诗词+古文为主；近代诗只收公版诗人（卒于 1976 前）；西方古典为远期扩展。
- 形态：Android 原生（Kotlin + Compose），离线优先，无社区、无账号、无信息流。
- 差异化：日期引擎（节气/物候/花信/节日）当脊柱 + "送出 App"（widget/推送/分享卡片）+ 现代极简 UI。

## D-006 功能框架与施工分块（2026-10-24）

- **A 数据底座**：chinese-poetry 清洗 → SQLite（poems/authors/collections/节气映射）；精选包+完整包
- **B 日推引擎**：农历/节气/花信计算 → 当日诗选择规则 → 每日 0 点轮转
- **C 阅读核心**：今日页、详情页（拼音开关/注释/译文/诗人小传）、搜索、收藏与自定义诗集
- **D 送出链路**：Glance widget、WorkManager 定时推送、Canvas 分享卡片
- **E 主题系统**：Material 3 + 传统色节气换肤 + 字体 + 深色模式
- **F 二期架位**：节气专题页、名句库、背诵挖空、竖排雅模式、近代诗架、TTS 朗诵、诗签/赠诗

施工顺序：A → B → C(今日+详情) → E → D → C(搜索+收藏) → 打磨。每块收尾由用户真机验收。

## D-007 UI 与功能参照定案（2026-10-25，用户试用后）

- **UI 主参照**：雅言（iOS 独占，古书样式美学、沉浸竖排、横竖切换）——取其"古书皮"
- **首页/分类/dock**：参考西窗烛（首页诗词卡片流+每日主题、文库分类导航）
- **功能广度**：参考京墨（文化工具箱式模块），数据库组织参考京墨（GPL：只参考思路，不碰代码）
- **分享卡片**：参考几枝（中国风笺纸卡片）
- **推荐逻辑**：今日诗词（情境：时间/节气/节日）+ 雅言（循物寻诗·意象主题）+ 西窗烛（每日主题）——全部本地化离线实现
- **明确排除**：拼音功能不做（用户定：怕出错，宁缺毋滥）
- **机会确认**：古书美学在 Android 端是空白（雅言 iOS 独占）→ 差异化加强
- **内容策略修订**：v1 不做白话译文；用**公版历代评点**（诗话类，无版权问题）+ 一句话题解 + 相关诗词（意象标签联动）替代
- **函匣候选新增**：「文学常识小词典」（词牌/平仄/意象/流派等概念速查）——作者本人即目标用户（缺文学常识的普通读者），v2 实现

## D-008 信息架构与模块定案（2026-10-25，选择题回收）

- **底部导航**：三 tab——今日 / 书库 / 我的；函匣不设独立 tab，作为书库内的入口
- **首页形态**：**纯沉浸**——打开即今日一首，无任何信息流（岛读式，用户拍板，否决了下拉主题流方案）
- **推论**：每日主题卡片流取消；主题内容并入书库的"主题诗单"浏览线
- **函匣模块**（住书库内）：名句（v1）、文学常识小词典（v2）、传统色+节气物候表（随主题系统）；**成语/歇后语不做**
- **雅言取材**：横竖排切换、循物寻诗（意象检索）、鉴赏页结构（公版评点+相关诗词+题解）；沉浸竖排不做默认，竖排作为切换选项

## D-009 发布与工程流程（2026-10-25）

- **分发**：GitHub Releases 首发（用户定案）；国内商店（软著+备案）远期再议
- **License**：Apache-2.0
- **签名**：为汲古独立生成 `jigu-release.jks`（RSA 4096，有效期 30 年+），按工作区惯例存 `C:\Work\keystore\`、凭据进项目 `keystore.properties`（gitignored）；**不复用** sekai lmc / ZZUPocket 的 key；发布页公布 SHA-256 指纹；密码另存密码管理器，keystore 三处备份（唯一副本不可再生）
- **版本号**：versionName 从 0.1.0 起，随阶段推进（0.1 数据底座、0.2 日推引擎…），v1.0.0 = 首个公开发布；versionCode = major×10000+minor×100+patch（0.1.0→100），**发版必升**；数据包独立 `dataVersion`（借鉴 PjskToolbox DatapackSchema.VERSION 教训：改结构不升号=静默不重导）

- **开发流程**：main + feature/* 短分支（一个验收单元一分支），conventional commits（feat/fix/data/docs/chore）；每阶段 = 一个 milestone，收尾走真机验收清单；阶段 7 起打 Release
- **环境事实（源自 DSH skill android-build-install）**：真机 MEIZU 21 Note（Android 16/API 36，1264×2780）；JDK 21；Gradle 8.9（华为云镜像）；compileSdk 36、minSdk 26；装包必须 adb push + pm install（adb install 不可靠）；gradle 首次写 ~/.gradle 会被沙箱拒需重试

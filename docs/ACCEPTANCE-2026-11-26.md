## A. dock 常驻（D-046）

- [ ] 诗词栏进任一诗集 → 点开一首诗详情：**底部 dock 仍在**（不再消失）。
- [ ] 古文栏进《史记》→ 详情页：dock 仍在。
- [ ] 我的 → 名句、诗历、收藏、关注诗人：dock 都在。
- [ ] "做卡片"预览页：dock **退场**（沉浸式，符合预期）。

## B. 作者索引（D-044a）

- [ ] 诗词栏 → 作者维度：顺序为**朝代时序**（屈原 → 曹操 → 蔡琰 → … 唐 → 宋 …）。
- [ ] 古文栏 → 作者维度：只有古文家（左丘明 / 老子 / 墨翟 / 荀况…），**不混李白柳永**。
- [ ] 每行右侧数字 = 该栏域内作品数（与点进去的列表条数对得上）。

## C. 诗历与搜索入口（D-044）

- [ ] 今日页右上角两枚小图标：🔍（搜索）与 ⏱（诗历）。
- [ ] 点 ⏱ → 按天倒序的句子时间线，有节气 badge；点某天的句子 → 直达全诗。
- [ ] 点 🔍 → 进诗词栏且**搜索框自动聚焦、键盘弹出**，可直接输入。
- [ ] 换一首几次，诗历里当天的记录跟着变成"最后展示的那句"。

## D. 情境推送（D-045）

- [ ] 我的 → "心情·状态"：心情 6 类可多选、状态 6 档单选（默认 = 不偏向）。
- [ ] 选"静夜读书" → 回今日页换一首几次，应落在读书/写月/惜时一类题材。
- [ ] 我的 → "天气配诗"填"杭州"保存（联网时）→ 今日页角标可能显示"今日·晴/雨"。
- [ ] 清空城市 → 立即回纯离线（之后不再任何联网）。

## E. 名句体系（D-046 R5）

- [ ] 我的 → 名句：顶部五枚 chips（全部 / 经典 / 诗词 / 古文 / 已收藏），切换内容随之变化。
- [ ] 名句行内点 ♡ → 变实心；进"我的收藏"能看到**该句所属原诗**；再点 ♡ 取消。

## F. 古文阅读器化（D-046 R8 / R7）

- [ ] 打开《史记》某篇（长篇散文）：顶部有"段落"按钮 → 弹出段落目录（第 N 段 + 首句预览）→ 点一段能跳过去。
- [ ] 读到中途退出，再进同一篇 → 自动回到上次位置（400ms 内静默恢复）。
- [ ] 行距/页边比上版松（行距 1.9、页边 32dp），标题层级不挤。
- [ ] 竖排模式：**不**恢复进度（按设计）。

## G. 书架置顶（D-046 R9）

- [ ] 诗词栏长按任一诗集卡 → 出现"●"标记并排到栏首；再长按取消。
- [ ] 古文栏长按置顶：置顶组先出，下面仍按四库分组，且不重复出现。

## H. 诗人主页与搜索（D-043）

- [ ] 搜"柳永" → 顶部**作者卡**（姓名/朝代/作品数）→ 点进诗人主页：身份区、小传折叠（>6 行可展开）、名篇、体裁 chips 四区整齐。
- [ ] 诗人页点"关注" → 我的 → 关注的诗人 列表里能看到；取消关注同理。
- [ ] 搜"衣带渐宽" → 名句行 → 点开《蝶恋花》，该句有淡朱底高亮。

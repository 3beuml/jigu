- 正文缩进树（全角空格）：

```
先秦诗卷一                      ← 卷标题，ind0
　　【歌上】                      ← 类目，ind2，方括号
　　【弹歌】                      ← 诗题，ind2，方括号
　　〖《吴越春秋》曰：…〗          ← 注/序，ind2，六角括号，丢弃
　　断竹续竹。飞土逐宍。（…）      ← 正文，ind2，句号断句
```

- 汉魏以降（如梁诗卷一）：

```
梁诗卷一                        ← 卷标题 ind0
　　梁武帝萧衍                    ← 作者 ind2，短行
　　〈衍。字叔达。兰陵武进人。…〉   ← 小传 ind2，尖括号，丢弃
　　【乐府】                      ← 组目 ind2
　　【芳树】                      ← 诗题 ind2
　　绿树始摇芳。芳生非一叶。…     ← 正文 ind2
```

- **难点**：作者行、诗题、正文**同为 ind2**，只能靠形态区分。实测发现两个可靠信号：
  1. 作者行**不带句号**、长度 ≤14、且下一条非空行是 `〈小传〉` 或 `【诗题】`；
  2. 诗题一律 `【…】` 全包裹；注文一律 `〖…〗`。

## 二、切分规则

1. 卷标题（`先秦诗卷一` … `隋诗卷十`，共 267 个）→ 重置作者/类目，定朝代。
2. `◎xxx` → 类目（如「◎释氏」）。
3. `〈…〉` → 作者小传，丢弃。
4. `〖…〗` → 注/序，丢弃且不改变状态。
5. `【…】` → 诗题（冲刷上一篇）。
6. 短行 + 无句号 + 下一行是 `〈`/`【` → 作者。
7. 其余 → 正文。
8. 正文清洗：剥行内 `〖…〗`；从第一个「（…○…）」处截断出处的校勘括注。

**朝代映射**（按卷标题前缀）：先秦诗→先秦、全汉诗→汉、魏诗→魏、晋诗→晋、宋诗→南朝宋、

## 五、已知边界（诚实说明）

1. **断句用「。」**：底本全角句号断句（逯书原貌），入库后 `PoemFormat` 会按句号分行，
   阅读观感与唐诗的「，/。」混排不同，属底本特征，未做改写。
2. **165 条残句**（如「候人猗兮。」）保留——原书就是辑佚残篇，符合 D-010 收录条例。
3. **29 条正文含序文**：原书把《史记》《家语》等出处引文与诗题并列，未强行切分（避免误伤正文）。
4. **未做异文对校**：底本括注中的「（文苑作X）」已随括注剥离，只保留正文；若需异文，应另立字段。

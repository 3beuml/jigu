## 一、体例侦察结论（决定了解析方案）

源文件 = **目录（1–6328 行）+ 正文（6329 行起）**。正文是缩进树，但**五个子编层深各不相同**：

| 子编 | 行范围 | 作者缩进 | 诗题缩进 | 特征 |
|---|---|---|---|---|
| 第一编 补全唐诗 | 6331–6609 | 2 | 3 | 无小传，直接「作者→诗题→正文」 |
| 补全唐诗拾遗 | 6610–6863 | 3 | 4 | 有 `ind0` 组诗总题（《涉道诗》二十八首） |
| 第二编 全唐诗补逸 | 6864–8588 | 3 | 4 | 作者后有 `ind0` 小传，诗题深一层 |
| 第三编 全唐诗续补遗 | 8589–10639 | 3 | 4 | 卷锚在 `ind0/1`，个别作者 `ind1` |
| 全唐诗续拾 | 10640–末尾 | 2 | 3 | 作者后有 `ind0` 小传 |

**关键教训**：先试过「前瞻 + 散文判别」的启发式（下一行更深=作者、顶格散文=小传），
反复误伤——诗句「今朝是何夕，良人谁难觌」被判成小传、卷内小集题「同音韵诗」被判成作者、
「留别女道士」这类诗题被写成作者名。**因为各编层深本来就不同，靠形态猜必然出错**。
最终改为**按编显式配置作者层/诗题层缩进**，切分完全确定、不再猜。

## 二、切分规则（确定性）

1. 编锚 → 载入该编 `(author_ind, title_ind)`。
2. 卷锚（`全唐诗补逸卷之N` / `卷N[某]`）→ 清空作者。
3. `ind >= title_ind` → 诗题（冲刷上一篇）。
4. `ind == author_ind` → 作者；若该行是「N首」/含书名号 → 组诗总题，不换作者；
   若是卷内集题（残诗集/赵志集）→ 记无名氏，继续收诗。
5. `ind == 0` → 已收到诗题则计正文；否则是作者小传，丢弃。
6. 行内 `【】〖〗` 夹注/校记一律剥除。

## 五、与 D-043 预期（~5,700 首）的差距说明

D-043 记档的 ~5,700 是**目录条目数**；实际可入库 1,485，差距来自三点，均为合理损耗：

1. **查重**：2,466 条与现库（《全唐诗》正编已收）题名+作者完全相同被丢弃——补编的性质正是"补缺"，
   但这套殆知阁合本里也混入了大量正编已收篇目。
2. **无正文**：113 条只有题/只有小传（残篇）。
3. **无作者**：334 条（目录里有题、正文区找不到可归属的作者行）。

**不注水原则**：宁可少收，不把「诗题当作者」「小传当正文」的脏数据塞进库。若日后要提量，
正确做法是补第二底本对校，而不是放宽切分规则。
